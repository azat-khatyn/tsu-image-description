## Назначение набора

Эксперту предлагается оценить:

1. Семантическую близость автоматически сгенерированного описания к экспертному эталону.
2. Удобочитаемость и архивный стиль русского языка.
3. Наличие/отсутствие фабрикаций — деталей, отсутствующих на изображении.
4. Пригодность описания как поискового признака.

## Известные ограничения метода

- Пайплайн не распознаёт именованные сущности (Адмиралтейство, Медный всадник, А. Гитлер).
- Пайплайн не извлекает текст с открытки (надписи, лозунги, подписи художника).
- Пайплайн не классифицирует историко-культурный контекст (блокада, праздничные кампании).

Эти ограничения — следствие выбора BLIP-1 в качестве базовой модели подписей (см. README → «Будущая работа»).
