# Данные оценки

Каноничный источник истины — манифест `data/eval/testset.jsonl` (одна строка на
изображение). Сами изображения не трекаются в git (`.gitignore`, `*.jpg`); трекается
манифест и эта документация. Пересобрать манифест: `python scripts/build_testset.py`.

Схема записи манифеста:

```json
{"image_path": "...", "source": "...", "role": "...",
 "reference_ru": null, "technique": null, "has_text": null}
```

## Страты

| Название | `source` | n | `role` | Происхождение | Эталоны |
|---|---|---|---|---|---|
| **НЭБ, «Ленинград в годы ВОВ»** | `neb_wwii` | 224 | reference_based | НЭБ, коллекция 529 (открытки) | экспертная RUSMARC-разметка (`reference_ru`, техника, год) |
| **НЭБ, общий набор** | `neb_diverse` | 220 | reference_free | НЭБ, поиск «открытка» + открытый доступ + Изодокументы | нет |
| **NYPL, общий набор** | `nypl_curated` | 200 | reference_free | NYPL, ручной отбор открыток + дедуп | нет |
| **Демонстрационный** | `semantic_demo` | 12 | demo | NYPL, малый семантический набор | частично |

Для retrieval-метрик используется **смешанный тестовый набор (НЭБ + NYPL)** — объединённый пул из всех страт (656 изображений) как галерея-дистрактор.

`role`:
- **reference_based** — есть экспертный эталон → метрики с эталоном.
- **reference_free** — эталона нет → метрики без эталона.
- **demo** — малый набор для качественной демонстрации версий пайплайна.

### Как получены

- **`neb_wwii`** — `scripts/data_preparation/scrape_neb_collection.py` по URL коллекции
  529 (rusneb.ru). Парсит каталожные карточки, тянет RUSMARC (заглавие, техника, год,
  тематические рубрики) и миниатюры. Это **единственная** легитимная экспертная разметка.
- **`neb_diverse`** — тот же скрейпер в режиме **поиска**:
  ```
  python scripts/data_preparation/scrape_neb_collection.py \
    --collection-url "https://rusneb.ru/search/?q=открытка&access[0]=open&c[]=23" \
    --output-dir data/neb_search_postcards --sample 220 --max-pages 50 --delay 1.5
  ```
  `--sample` берёт случайную выборку (seed=42) из перечисленных ID → тематический
  разброс (городские виды, праздники, портреты, натюрморты…), снимая перекос ВОВ-коллекции.
  Метаданные у этих записей в другом формате и не парсятся → только изображения (для
  reference-free достаточно).
- **`nypl_curated`** — открытки NYPL, отобранные вручную, с проверкой на дубликаты по
  содержимому (md5). Чистый доменный срез (другой издатель/страна).
- **`semantic_demo`** — `data/eval/semantic_testset.jsonl` (малый набор для демонстраций).

> Самостоятельно введённые описания РГБ-открыток (прежний `references.jsonl`) **удалены**:
> их нельзя считать эталонными. Все эталоны теперь — только из НЭБ (`neb_wwii`).

## Какая метрика на какой страте

| Метрика | Нужны эталоны | Страты |
|---|---|---|
| **CLIPScore** (reference-free) | нет | все (`neb_*`, `nypl_curated`) |
| **Cross-modal retrieval** R@k | нет (нужен пул-дистрактор) | `neb_diverse` + `nypl_curated` как запросы; они же — пул |
| **BERTScore_RU / chrF / ROUGE-L / BLEU** | да | `neb_wwii` |
| **OCR** CER/WER | ручные транскрипты | OCR-сабсет: открытки с **крупным** текстом из `neb_*` |

Узкодоменность `neb_wwii` (только ВОВ) — причина, по которой он используется как
**reference-based исследование**, а не как глобальный тест; тематическую репрезентативность
обеспечивают `neb_diverse` + `nypl_curated`.

## Разрешение

Миниатюры НЭБ — 315×460 (полное скрыто за JS-viewer). Для BLIP (вход 384), SigLIP/CLIP
(224) этого достаточно — влияния на подпись/метаданные/CLIPScore/retrieval практически нет.
**Исключение — OCR**: мелкий текст в миниатюре не распознаётся; OCR-сабсет берёт открытки
с крупными надписями (или для них дотягивается полное разрешение).

## Анализ эмбеддингов

Разведочные фигуры (`docs/figures`) строятся из кэша `embed_export`: доменный сдвиг,
кросс-модальная привязка, геометрия уверенности/OOD. Метрики качества они не дают — только
разведка пространства признаков.

`data/semart` (репродукции живописи) подмешивается **только** в фигуру доменного сдвига как
внешний доменный референс (показать, что наши открытки и живопись занимают разные области).
В тест-набор и метрики качества SemArt не входит.
